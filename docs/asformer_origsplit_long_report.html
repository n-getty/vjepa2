Technical report · SAR-RARP50 surgical gesture recognition

ASFormer head + V-JEPA backbone — long schedule, soft class weights

Frozen V-JEPA backbone paired with an ASFormer action-segmentation head on the SAR-RARP50 challenge split. Schedule extended from 30 to 130 epochs, class weights softened (cap at 8× median, mean-normalised) per the LemonFM report recipe.

1 · What was trained

1.1   Two-stage pipeline

The pipeline follows the standard frozen-backbone + lightweight temporal head pattern used by SAR-RARP50 challenge winners. The backbone is frozen throughout training; only the ~1M-parameter ASFormer head is updated.

What the curves show

Train acc climbs steadily from 30% (ep 1) to ~99% (ep 129) — the head fits the train set near-perfectly. Val acc rises sharply for the first 30 epochs (45% → 76%), then plateaus around 76–79% with no monotonic gain after epoch 66. Val loss starts rising after epoch ~30 even as val acc holds; this is the classic overfitting signature for a tiny head trained on a frozen feature cache. Best val_acc and best val_f1 land at different epochs (66 vs 83), which is why both checkpoints are tracked separately.

5 · Note on split coverage (vs the LemonFM report's split)

A second SAR-RARP50 split is widely cited — the “6+1+3” split used in the LemonFM report: train on videos 04, 07, 08, 09, 10, 36, 44; val on 45; test on 41, 42, 43. While running the experiments above, we also counted per-class label frequencies in that split to compare it to the challenge split this run used. The result is non-trivial enough to be worth flagging.

Coverage problems in the 6+1+3 newsplit

  • val (video_45) is missing 2 of the 8 classes: zero frames of G5_tying_knot AND G6_cutting_suture exist in the val partition. Any model-selection metric computed on this val set is structurally blind to whether the head can predict either gesture — those classes contribute 0/0 to recall and 0/x to precision (= 0 F1, ignored by macro-F1 averaging on this set).
  • test (videos 41+42+43) is missing G5_tying_knot entirely: the model can never be wrong about tying_knot on this test set because the class literally never occurs. Macro-F1 reported on this test set is an average over 7 classes, not 8.
  • train has only 7 videos: 34k per-frame labels vs the challenge split's 272k — ~8× smaller. Surgeon-style and instrument-pose variance is correspondingly narrower; G5 and G6 each have under 1,500 training frames.

The challenge split (used by this report's training run) avoids all three problems: all 8 classes appear in every partition, the training set is 8× larger, and val/test cover 16 different operations between them rather than 4. The trade-off is that its train and test distributions are correspondingly wider — harder to fit but more honest about generalisation across surgeons and devices.

Practical implication for cross-paper comparisons: numbers reported on the 6+1+3 newsplit and on the challenge split are not directly comparable. A run that scores high on newsplit test may be overconfident about G3/G4 because half of the challenge's rare-class burden is absent from the eval. When we evaluated this run's checkpoint on the newsplit-style 1Hz cadence in a separate experiment (asformer_sarrarp50_distilled_long/), it landed around 63–66% test acc — comparable to the LemonFM report's own numbers on the same restricted split, but ~14pp lower than the 77.4% reported here, which uses 10 test videos and all 8 classes.
